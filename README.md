# ChinaLink PWA

Visa applications, document upload, tracking, and chat, in 中文 / English.
Built with React + Vite, hosted on Vercel, data in Supabase.

Environment variables (set in Vercel, never in the code):
- VITE_SUPABASE_URL
- VITE_SUPABASE_ANON_KEY

Run `schema.sql` once in the Supabase SQL Editor to create the database.
